Latest wins
One pair at a time

จับคู่ด้วย QR โดยไม่ต้องสมัครสมาชิก

Display Device

เปิด Display Mode, สร้าง QR payload และ publish pairing code ไป Firebase เมื่อจับคู่แล้ว QR จะถูกซ่อนและแสดงสถานะ Connected

Main Device

สแกน QR, claim pairing ด้วย anonymous auth และบันทึก peer info เพื่อส่งคำสั่ง Cloud หรือ local fallback

เปลี่ยนคู่

กด Disconnect/Reset บน Display หรือ Clear Pairing บน Main ก่อนเชื่อมอุปกรณ์ใหม่ เพื่อรักษาหลักการหนึ่งคู่ต่อครั้ง

กู้คืนหลัง process ถูกปิด

ถ้าอุปกรณ์ยังอยู่ในบทบาท Display แอปจะร้องขอเริ่ม Display service กลับเมื่อ process เปิดใหม่

Display anti-theft

แจ้งเตือนเป็นขั้น ไม่ขัดกับการรับเส้นทาง

1

Arm ด้วยสาย 3.5 มม.

ผู้ใช้ตั้ง PIN และเปิดระบบเอง ระบบจะเริ่มเฝ้าระวังเมื่อ trigger เสียบอยู่

Armed
2

ถอดสาย

แสดง Security Verification และให้เวลาใส่ PIN โดยยังไม่เปิดเผยหน้า Home ของแอป

Challenge
3

ผิด/หมดเวลา

ส่ง alert พร้อมตำแหน่งล่าสุดไป Main จากนั้นเริ่มเสียงเตือนและยกระดับเป็น full-screen lock

Escalate
4

ปลดด้วย PIN ถูกต้อง

หยุด alarm, ยกเลิก timer และกลับสู่สถานะพร้อมใช้งาน

Disarmed
ขณะ anti-theft challenge/alarm ทำงาน ระบบจะพักการเปิด Maps และการล็อกเครื่องจากเหตุการณ์ถอดสายชาร์จ เพื่อให้หน้าป้อน PIN ยังคงมองเห็นและใช้งานได้
Display readiness

ปลุกจอ ปรับแสง และล็อกเฉพาะเครื่อง Display

เสียบไฟ

เมื่อเปิด automation และเครื่องอยู่ในบทบาท Display ระบบใช้ profile กลางวัน/กลางคืน พร้อมปลุกจอแบบ best effort

ถอดไฟ

หรี่หน้าจอและล็อกเครื่องเมื่อเปิด Lock on Disconnect และอนุญาต Device Admin แล้ว

Service ถูก OEM ปิด

manifest receiver ยังคงรับเหตุการณ์ power ได้ โดยไม่ผูกกับอายุของ Display service เพียงอย่างเดียว

ความปลอดภัย

Power automation จะไม่ทำงานบนเครื่อง Main และไม่แทรกแซงขณะ anti-theft กำลังบังคับยืนยัน PIN
