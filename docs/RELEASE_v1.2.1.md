# PHANToM GO v1.2.1

วันที่: 2026-06-29 • Stable • versionCode 28

## สรุป
แก้บั๊กสำคัญของการรวม/ส่งออกคลิป dashcam และปรับหน้าจอเลือกช่วงเวลา (timeline) ให้ใช้งานง่ายขึ้น

## แก้ไข
- **กันไฟล์เสียเมื่อรวมคลิปคร่อมการเปลี่ยนคุณภาพ (720p/1080p)**: เดิมการรวมเทียบแค่ชนิดโคเดก ทำให้ช่วงที่คร่อมการสลับคุณภาพได้ไฟล์เสียหรือได้แค่ช่วงแรก ตอนนี้เลือกความละเอียดที่ครอบคลุม footage มากสุดและรวมเฉพาะส่วนที่เข้ากันได้
- **กันสับสนเมื่อเริ่มส่งออกซ้อน**: ถ้ามีงานส่งออกกำลังทำงานอยู่ จะแจ้งเตือนและแสดงความคืบหน้าของงานเดิม แทนที่จะรีเซ็ตหลอกตา
- **ปุ่มยกเลิกหยุดงานได้จริงตอนบันทึกเข้าแกลเลอรี**: เดิมยกเลิกแล้วขั้นคัดลอกไฟล์ยังทำต่อจนจบ
- **ไม่ทำให้ "แตะเพื่อแชร์" ของงานก่อนหน้าพัง**: เดิมการส่งออกรอบใหม่ลบไฟล์แคชทั้งหมด ตอนนี้ลบเฉพาะไฟล์เก่ากว่า 6 ชั่วโมง

## ปรับปรุง
- **เลือกช่วงเวลาแบบไทม์ไลน์ใหม่**: ค่าเริ่มต้นคลุมทั้งช่วง (ปุ่มอยู่สุดสองข้าง) และเป็น 2 แถบ — แถบบนเป็นภาพรวมพร้อมปุ่มคู่ตีกรอบ แถบล่างแสดง footage ในกรอบแบบซูมตาม (เลื่อนเข้า=ซูมเข้า เลื่อนออก=ซูมออก)

## ข้อจำกัด
- หากช่วงที่เลือกคร่อมการเปลี่ยนคุณภาพ ไฟล์ที่ได้จะมีเฉพาะ footage ของความละเอียดที่ครอบคลุมมากสุด (ส่วนอีกความละเอียดถูกข้ามเพื่อไม่ให้ไฟล์เสีย) ความยาวที่ได้จึงอาจน้อยกว่ากรอบที่เลือก
