# PHANToM GO v1.2.0

วันที่: 2026-06-29 • Stable • versionCode 27

## ไฮไลต์

ปรับปรุงประสบการณ์ฟีเจอร์กล้องติดรถ (GO Cam) ครั้งใหญ่: ลื่นขึ้นเมื่อใช้ร่วมกับแผนที่, กันสั่น, และเครื่องมือจัดการ/ส่งออกคลิปแบบใหม่

## มีอะไรใหม่

### ลื่นขึ้นเมื่อเปิด Google Maps ขณะอัด
- เลือก **ความละเอียดวิดีโอได้ (720p ค่าเริ่มต้น / 1080p)** — 720p ลดภาระ encoder ราวครึ่งหนึ่ง ทำให้เครื่องไม่หน่วงเมื่อเปิดแผนที่ไปพร้อมกัน
- ปรับการวาดวันเวลาบนวิดีโอให้เบาลง (ยังฝังเวลาให้ทุกเฟรมเหมือนเดิม)

### กันสั่นวิดีโอ (Stabilization)
- เปิด/ปิดได้ในหน้า Settings (ค่าเริ่มต้นเปิด) ใช้ระบบกันสั่นของกล้อง (EIS/OIS) เฉพาะเครื่องที่รองรับ
- หมายเหตุ: กันสั่นจะครอปมุมภาพลงเล็กน้อย และทำงานกับกล้องเดี่ยว

### จัดการ/ส่งออกคลิปแบบใหม่
- **เลือกช่วงเวลาด้วยไทม์ไลน์**: ลากที่จับ 2 ตัวเลือกช่วงใดก็ได้จาก footage
- **รวมทั้งช่วงการอัด (session)**: รวมคลิปต่อเนื่องตั้งแต่เริ่มจนหยุดเป็นไฟล์เดียว
- **ส่งออก/รวมคลิปแบบไม่ re-encode** (เร็ว คงคุณภาพเดิม) เลือกบันทึกเข้าแกลเลอรีหรือแชร์ออก
- **Popup ความคืบหน้า**: แสดงเปอร์เซ็นต์ + เวลาโดยประมาณ พร้อมปุ่ม **ยกเลิก** และ **ทำงานเบื้องหลัง** (ทำงานต่อพร้อมแจ้งเตือนบน status bar)

### อื่น ๆ
- คลิปแบ่งเป็นเซ็กเมนต์ละ 1 นาที (กันไฟล์เสียเมื่อไฟดับ + เลือกช่วงได้แม่นยำขึ้น)

## ผลกระทบต่อผู้ใช้
- ค่าเริ่มต้นความละเอียดเป็น 720p (ปรับเป็น 1080p ได้ในหน้า Settings)
- คลิปที่อัดด้วยรุ่นก่อน v1.1.1 (เก็บใน public storage) จะไม่แสดงในเบราว์เซอร์รุ่นใหม่ (รุ่นใหม่เก็บแบบส่วนตัว)

## ข้อจำกัด
- กันสั่นขึ้นกับฮาร์ดแวร์ และครอปมุมภาพลงเล็กน้อย
- ถ้าปิดสิทธิ์แจ้งเตือน การ "ทำงานเบื้องหลัง" จะไม่มีแจ้งเตือนบน status bar (popup ยังใช้ได้)
- session ที่ยาวมากจะใช้เวลารวมไฟล์นานและได้ไฟล์ขนาดใหญ่
