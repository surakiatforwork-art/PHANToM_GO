# PHANToM GO v1.3.0

วันที่: 2026-06-30 • Stable • versionCode 30

## สรุป
รุ่นนี้เน้นฟีเจอร์และความลื่นของกล้องติดรถ (GO Cam / Dashcam) เพิ่มระบบกันสั่นวิดีโอด้วยซอฟต์แวร์, ลดอาการหน่วงขณะอัด, ปรับตัวเลือกช่วงเวลาให้เลือกแม่นยำขึ้น และแก้พฤติกรรมหน้าจอ/ปุ่มในโหมดจอ

## มีอะไรใหม่

### กล้องติดรถ (GO Cam)
- **กันสั่นวิดีโอด้วยซอฟต์แวร์ (ใหม่)**: สำหรับเครื่องที่ไม่มีกันสั่นด้วยฮาร์ดแวร์ — กดค้างที่คลิปในหน้า "วิดีโอที่บันทึก" → เลือก "Stabilize and save" → เลือกระดับครอป (เบา/กลาง/แรง) ระบบประมวลผลแบบเบื้องหลัง (ยกเลิก/ทำต่อพื้นหลังได้) แล้วบันทึกลงแกลเลอรี ทำงานแบบ post-process ไม่กระทบการอัดสด
- **ลดอาการหน่วง/ค้างขณะอัด**: ย้ายงานเขียนไฟล์/จัดเก็บ/ตัดโควตาออกจากเธรดหลัก, เลิกอ่าน metadata ทุกไฟล์ในจังหวะอัด, และตัดเก็บโควตาเป็นช่วงแทนทุก ๆ นาที
- **ตัวเลือกช่วงเวลา export แม่นยำขึ้น (zoom/pan)**: ลาก handle เพื่อเลือกช่วง — ลากชิดขอบเพื่อซูมออก, ปล่อยมือเพื่อซูมเข้าหา selection (handle จะใหญ่ขึ้นตามการซูม), และเลื่อนแถบล่างซ้าย-ขวาเพื่อ scrub หา footage ได้ตรงจุด

### โหมดจอ (Display)
- **แก้ปุ่มสลับโหมดจอ**: กดเปิดครั้งเดียวสถานะอัปเดตทันที ไม่ต้องกดซ้ำ
- **จอไม่ดับขณะใช้งานโหมดจอ**: ขณะเปิดโหมดจอและเสียบไฟ หน้าจอจะ active ตลอดแม้อยู่ในแอปอื่น (เช่น Google Maps); เมื่อถอดไฟจะปล่อยให้ทำงานตามปกติ (ไม่ชนระบบล็อกเมื่อถอดไฟ)

### อื่น ๆ
- จำกัด APK เป็น arm64-v8a และใช้ OpenCV 4.13.0 ที่ align 16 KB page size แล้ว จึงไม่มีคำเตือนความเข้ากันได้บน Android 15
- เพิ่มเอกสาร `project_info.md` สรุปฟีเจอร์/โค้ดสำหรับผู้ดูแลโปรเจกต์

## ทดสอบที่รันจริง (เครื่องจริง Android 15, arm64)
- `clean assembleDebug assembleRelease lintDebug testDebugUnitTest` ผ่านทุกโมดูล
- กันสั่น: อัด 1080p ~1 นาที → stabilize → ได้ไฟล์เล่นได้ สีถูก ภาพตั้งตรง ความยาวเท่าเดิม
- อัด → หยุด → คลิปถูกบันทึกและแสดงในรายการ (ไม่มีไฟล์ค้าง `.pending-`)
- โหมดจอ: toggle เปิดครั้งเดียวสถานะตรง; ตรวจ `dumpsys power` พบ screen wake lock ถูกถือไว้และปล่อยเมื่อปิดโหมดจอ
- ตัวเลือกช่วงเวลา: ทดสอบ zoom-in ตอนปล่อย, ซูมออกเมื่อลากชิดขอบ, และ pan แถบล่าง
- ติดตั้งบนเครื่องจริง 2 เครื่องด้วย `adb install -r`

## ข้อจำกัดที่ทราบ
- **ตัดการรองรับเครื่อง 32-bit เท่านั้น** (รุ่นเก่ามาก) จากการ ship เฉพาะ arm64-v8a — เครื่องสมัยใหม่ไม่กระทบ
- กันสั่นช่วยเรื่องความนิ่งเท่านั้น ไม่เพิ่มรายละเอียดของทะเบียนที่เบลออยู่แล้ว และช้ากว่าเวลาจริงบนเครื่องระดับกลาง
- จอ active ตลอดผูกกับ "โหมดจอเปิด + เสียบไฟ" (ถอดไฟจะไม่บังคับจอติด เพื่อไม่ชนระบบล็อกเมื่อถอดไฟและประหยัดแบต)
