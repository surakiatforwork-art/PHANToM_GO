# PHANToM GO v1.1.0

วันที่: 2026-06-26 • Stable • versionCode 25

## ไฮไลต์

ฟีเจอร์ใหม่ใหญ่: **กล้องติดรถ (Dashcam)** รวมเข้าแอปหลักแล้ว พร้อมปรับปรุงความเสถียรของการบันทึก และปรับฟีเจอร์ "เปิดแอปหลังส่ง"

## มีอะไรใหม่/เปลี่ยนแปลง

### กล้องติดรถ (Dashcam)
- รวมโค้ด dashcam จากแอปทดสอบ GO Cam เป็น shared library ใช้ร่วมกับแอปหลัก
- **Settings**: เลือกโหมดกล้อง (หลัง/หน้า/คู่), เปิด-ปิดพรีวิว, ตั้งโควตาพื้นที่จัดเก็บแบบวนลูป, ดูวีดิโอทั้งหมด
- **Security**: เปิด-ปิดฟีเจอร์, บันทึกอัตโนมัติเมื่อเสียบชาร์จ, แสดงสถานะ และดูคลิปย้อนหลัง
- หน้ารวมคลิป เรียงล่าสุดก่อน แสดงชื่อ/วันเวลา/ขนาดไฟล์ แตะเล่นได้

### ความเสถียรการตรวจจับไฟชาร์จ (ให้เทียบเท่าระบบ ปลุก/ล็อคจอ)
- เพิ่ม watchdog poll และ debounce ในการตรวจจับเสียบ/ถอดสายชาร์จของ dashcam
- เพิ่มการเริ่มทำงานหลังรีบูต/อัปเดตแอป: boot มาแล้วถ้ากำลังชาร์จอยู่ → เริ่มบันทึกทันที

### กันไฟล์วิดีโอเสียเมื่อไฟดับกะทันหัน
- บันทึกแบบ **แบ่งเซ็กเมนต์** (เซ็กเมนต์ละ ~2 นาที) แต่ละเซ็กเมนต์ปิดไฟล์สมบูรณ์ในตัว
- ไฟดับปุบปับ → เสียอย่างมากแค่เซ็กเมนต์ที่กำลังอัด (≤2 นาที) คลิปก่อนหน้าทั้งหมดยังเล่นได้
- กรณีดับเครื่องในรถ (ถอดไฟปกติ) ระบบสั่งหยุด/ปิดไฟล์ให้อยู่แล้ว

### เปิดแอปหลังส่ง (เดิม "เปิด Google Maps หลังส่ง")
- เปลี่ยนเป็น **เลือกแอปใดก็ได้** ในเครื่องให้เปิดต่อหลังส่งข้อมูลไปยังจอ
- มีสวิตช์เปิด-ปิดชัดเจน และตัวเลือกแอปแสดง **ไอคอน + ชื่อ**
- ถ้าแอปที่เลือกเปิดลิงก์ปลายทางได้ (เช่นแอปแผนที่) จะเปิดพร้อมจุดหมาย

## ผลกระทบต่อผู้ใช้
- ต้องตั้งค่ากล้อง/สิทธิ์ในแอปหลักใหม่ (ค่าจากแอปทดสอบ GO Cam ไม่ย้ายตามมา) แต่คลิปเดิมใน `Movies/PHANToM GO Cam` ยังเห็นได้
- ผู้ที่เคยเปิด "เปิด Google Maps หลังส่ง" ต้องไปเลือกแอปใหม่ในหน้า Settings

## ข้อจำกัด
- โหมดกล้องคู่ขึ้นกับฮาร์ดแวร์
- การเปิดกล้องอัตโนมัติจากเบื้องหลัง (Android 12+) อาจต้องอนุญาต "แสดงทับแอปอื่น"
- เซ็กเมนต์สุดท้ายที่กำลังอัดตอนไฟหายทันทีจริง ๆ ยังเสียได้ (≤2 นาที) ตามข้อจำกัดของระบบไฟล์
